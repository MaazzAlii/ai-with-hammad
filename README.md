# AI with Hammad 🚀

> **AI Automation Agency Website** — Automating business operations with n8n workflows, custom API integrations, and agentic AI systems.

## 🌟 Overview
This repository contains the official website for **AI with Hammad**. Built with modern responsive web design, interactive UI elements, smooth micro-animations, and glassmorphism design.

## ⚡ Features
- **n8n Workflow Automation**: Showcase of automated business processes & lead pipelines.
- **Custom API Integrations**: Seamless connections between CRMs, payment gateways, and databases.
- **Agentic AI Systems**: Intelligent AI agents designed to handle round-the-clock operations.
- **Responsive & Dynamic Design**: Built with vanilla HTML5, CSS3, and JavaScript with interactive counter animations and glassmorphism styling.

## 🚀 Live Demo & Usage
To run the website locally:
1. Clone this repository:
   ```bash
   git clone https://github.com/MaazzAlii/ai-with-hammad.git
   ```
2. Open `index.html` in your web browser, or serve it using any HTTP server (e.g. `npx serve` or Live Server).
